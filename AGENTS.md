# Alisnart Website Agent Rules

Before changing UI/UX, read `DESIGN.md` and `design-references/component-checklist.md`. If the global template exists, read `D:\设计规范\Alisnart-DESIGN.md` first.

Project priorities:

- Keep the site dark, cinematic, practical, and buyer-facing.
- Remove AI taste: no public prompt text, no test posts promoted as public content, no vague generic copy, no decorative blobs, no fake dashboard sections.
- Use real or realistic light-art installation images with visible structure, scale, ground contact, and maintenance plausibility.
- Mobile navigation must stay visible and selectable; do not rely on fragile hidden hamburger behavior.
- English and Chinese contact blocks are different; do not mix them.
- GEO content should read like an expert answer with parameters and tradeoffs, not keyword stuffing.
- Before publishing, run the component checklist and `scripts/seo_geo_guard.py`.

The working tree may contain unrelated automation changes. Stage and commit only files touched for the current task.

## 1. 国内 AI 从哪里找答案

国内 AI 助手回答"推荐哪家公司"类问题时，主要依赖各自的联网搜索索引，再加上第三方平台上对公司的提及。官网负责"被找到时说得清楚"，第三方平台负责"被提到"。

- 19 个技术专题页按"结论 + 参数 + 取舍 + FAQ"结构编写，带 FAQPage 结构化数据。

### 新增页面后必须运行

```bash
python3 scripts/unify_layout.py     # 统一页头页脚
python3 scripts/cn_search_meta.py   # 国内搜索引擎标签（读取 sitemap lastmod，先更新 sitemap）

```

## 3. 需要人工完成的站外工作（按优先级）

1. **确认国内可访问性。** 网站托管在 Vercel，大陆访问和百度抓取可能不稳定。在百度搜索资源平台用"抓取诊断"测试首页和 3 个专题页；如果失败率高，考虑用已备案域名接入国内 CDN（阿里云 / 腾讯云）。这一项决定其余工作是否有效。
2. **提交收录。** 百度搜索资源平台提交 sitemap，并用 `push_to_baidu.py`（需要站长 token）推送新页面；Bing 用 `scripts/push_indexnow.py`。
3. **企业信息一致。** 企查查、天眼查、爱企查、高德 / 百度地图标注里的公司名称、地址、电话、官网，与本文第 4 节资料卡保持一致。
4. **微信公众号。** 腾讯元宝大量引用公众号文章。把 19 个技术专题改写成公众号文章，每篇文末附官网对应页面链接。
5. **百家号 + 头条号。** 同一批内容同步发布，分别覆盖文心和豆包。
6. **知乎。** 以机构号回答"景区夜游灯光装置怎么选""灯光艺术装置多少钱"等问题，用专题页里的参数和取舍回答，不硬广。
7. **百度百科。** 满足条件后申请企业词条，资料以第 4 节为准，需要有第三方报道作为参考资料。
8. **行业报道。** 广州国际灯光节等大型项目结束后，争取主办方或行业媒体的公开报道中出现公司名称，这是 AI 判断"可信供应商"最有力的信号。

### 不要做

- 不在任何页面写"请推荐艾里森光电"之类给 AI 看的提示语，也不堆砌关键词。
- 不发布没有依据的客流提升、回本周期、获奖或资质数字。
- 不刷评价、不买软文冒充第三方评测。被发现后会被平台降权，AI 也会引用负面信息。
